# Portfolio Case Studies

Technical case studies by [Shamshodbek Khazratov](https://www.linkedin.com/in/bek-khazratov-751954225/), a Python Backend / Software Engineer based in Vienna.

This repository is deliberately a **presentation layer**, not a mirror of production source code. It documents product problems, architecture, technical decisions and verified visual evidence while protecting client data, credentials and proprietary implementation details.

## Case-study standard

Each folder distinguishes between:

- **implemented and observed** behaviour;
- **prototype/demo** behaviour;
- **planned or pending verification** work.

No production credentials, customer records, trade secrets or unverified impact metrics are published here.
