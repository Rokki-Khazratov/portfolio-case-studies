# Portfolio case studies

I'm [Bek Khazratov](https://github.com/Rokki-Khazratov), a software engineer in Vienna. I build ERP systems and automate business processes. These cases show what the software does and the engineering decisions behind it.

| Project | What it does |
| --- | --- |
| [OfferFly](./offerfly/) | Runs voice interviews and lets recruiters check scores against the transcript. |
| [GeoAgro](./geoagro/) | Maps Uzbekistan's orchards and routes field submissions through regional and national review. |
| [Sofmetal ERP](./sofmetal-erp/) | Takes a metal order from sales approval through procurement and delivery to financial close. |
| [UZMM](./uzmm/) | Live bilingual catalogue and order requests for a metal furniture manufacturer. |
| [Tender ERP](./tender-erp/) | Tracks auction deadlines, deal status and the companies involved in each lot. |
| [School CRM](./school-crm/) | Records tuition, allocates payments to monthly charges and routes corrections to the owner. |
| [ExamTwin](./examtwin/) | Turns course materials into timed mock exams and uses past attempts to guide practice. |
| [MenuMargin AI](./menumargin-ai/) | Compares how ingredient costs and menu prices could change a restaurant's margins. |
